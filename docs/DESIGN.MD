# Design System

## Overall Direction
- Clean, cozy business dashboard
- "Cozy" means warm and approachable rather than sterile or overly corporate
- Desktop-first
- Prioritize usability over decorative design
- Consistent design across tools

## Layout
- Persistent sidebar for navigating between tools
- Main content fills available screen space efficiently
- Columnar with cards that encapsulate different pieces of information or functionality within tools

## Style
- Minimal
- Subtle borders and shadows
- Avoid excessive whitespace
- Avoid excessive animations

## Design Process

The design will evolve as features are implemented

When creating a new UI:
1. Follow established patterns from the existing application
2. Use reasonable modern UI defaults where no preference is specified
3. Do not invent a new visual pattern if an existing one works
